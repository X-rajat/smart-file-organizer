# Changelog

## [1.0.0] - 2026-09-29

### Added
- Sorts files into 20 categories (100+ extensions), with sub-folders for documents, images, software and design files
- Preview (dry-run) mode
- Undo script and log written for every run
- Automatic renaming on name clashes
- Optional tidying of loose folders into `_Folders`
- Optional removal of empty sub-folders
- Protection for system folders, drive roots and the user profile
- Command-line switches: `/preview`, `/folders`, `/clean`, `/yes`, `/help`
